# 記事一覧表示

## 概要

記事一覧表示機能は、ユーザが保存した記事を一覧で確認し、タグでの絞り込み、並び替え、ページング、表示形式の切り替えを行う機能。

画面は `/users/[userId]/articles` で提供する。

一覧データは API route 経由ではなく、サーバ側で Prisma から直接取得する。

## 画面フロー

記事一覧表示は次の流れで表示する。

1. URL の searchParams を一覧の表示条件に変換する
2. ユーザのタグ一覧を取得する
3. searchParams で指定されたタグ ID を、ユーザが所有するタグだけに絞る
4. 表示条件に一致する記事件数を取得し、ページング情報を作る
5. 現在ページに表示する記事を取得する
6. 記事一覧、タグ絞り込み、表示形式、並び順、ページングを表示する

記事一覧の取得に失敗した場合は、空の一覧とエラーメッセージを表示する。

## 表示条件

記事一覧では次の searchParams を扱う。

| パラメータ | 内容 | 既定値 |
| --- | --- | --- |
| `page` | 表示するページ番号 | `1` |
| `sort` | 並び順 | `newest` |
| `tag` | 絞り込み対象のタグ ID | なし |

`tag` は複数指定できる。

利用できる並び順は次の通り。

| 値 | 内容 |
| --- | --- |
| `newest` | 作成日時の新しい順 |
| `oldest` | 作成日時の古い順 |
| `title` | タイトル順 |

不正な `sort` が指定された場合は `newest` として扱う。

`page` はページ番号として扱える値だけを利用する。

`tag` は、指定されたユーザが所有するタグ ID だけを有効な絞り込み条件として扱う。

## データ取得

記事一覧ページでは、サーバ側で次のデータを取得する。

1. ユーザが所有するタグ一覧
2. 表示条件に一致する記事件数
3. 現在ページに表示する記事一覧

記事一覧の取得では、`articles` に加えて次の関連データを読み込む。

- `article_sources`
- `article_tags_articles`
- `article_tags`

1ページあたりの記事数は 6 件。

タグで絞り込む場合は、選択されたタグ ID のいずれかに紐づく記事を表示する。

## 表示内容

記事一覧では、記事ごとに次の項目を表示する。

- 記事タイトル
- 記事本文のプレビュー
- 投稿日
- 入力元の種類
- 元記事へのリンク
- お気に入り状態
- 紐づくタグ

記事タイトルから記事詳細画面へ遷移できる。

元記事へのリンクは別タブで開く。

投稿日がない場合は `投稿日不明` と表示する。

表示形式は `grid` と `list` を切り替えられる。

## エラー・空状態

記事一覧の取得時にデータ不整合を検出した場合は、`記事一覧の取得に失敗しました` と表示する。

その他の取得失敗では、`内部サーバエラーが発生しました` と表示する。

表示対象の記事が 0 件の場合は、`記事が見つかりませんでした` と表示する。

## 現状の注意点

記事一覧表示は一覧専用の API route を持たず、サーバ側の page 実装から Prisma を直接呼び出している。

一覧の表示形式はクライアント側の状態として保持し、URL には反映しない。

タグ絞り込み、並び順、ページ番号は URL の searchParams に反映する。
