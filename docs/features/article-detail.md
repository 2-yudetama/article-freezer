# 記事詳細表示

## 概要

記事詳細表示機能は、ユーザが保存した特定の記事の本文、コメント、タグ、元記事リンクを確認する機能。

画面は `/users/[userId]/articles/[article_id]` で提供する。

詳細データは API route 経由ではなく、サーバ側で Prisma から直接取得する。

## 画面フロー

記事詳細表示は次の流れで表示する。

1. URL の `userId` と `article_id` を取得する
2. 指定ユーザが所有する記事を取得する
3. 記事に紐づく入力元、コメント、タグを取得する
4. 記事本文、コメント、タグ、元記事リンクを表示する

記事が見つからない場合は 404 として扱う。

## データ取得

記事詳細ページでは、サーバ側で次のデータを取得する。

- 記事本体
- `article_sources`
- `article_comments`
- `article_tags_articles`
- `article_tags`

## 表示内容

記事詳細では次の項目を表示する。

- 記事タイトル
- 記事本文
- 投稿日
- 保存日
- 入力元の種類
- 元記事へのリンク
- お気に入り状態
- 紐づくタグ
- コメント
- コメント更新日時

元記事へのリンクは別タブで開く。

投稿日がない場合は `投稿日不明` と表示する。

お気に入り状態は、お気に入りの記事の場合のみ表示する。

コメントがない場合、コメント欄は表示しない。

タグを押すと、記事一覧のタグ絞り込みへ遷移する。

## 現状の注意点

記事詳細表示は詳細専用の API route を持たず、サーバ側の page 実装から Prisma を直接呼び出している。

編集画面への導線はあるが、編集画面は mock データを参照している。保存は画面遷移とトースト表示のみで永続化は未実装。

削除ボタンと確認ダイアログは表示しているが、削除処理は未実装。
